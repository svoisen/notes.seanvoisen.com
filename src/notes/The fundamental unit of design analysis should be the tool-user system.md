Effective tool design requires analyzing the tool-user system as a unified whole, focusing on the information flow and feedback loops between user and tool rather than treating them as separate concepts.

In order to build better tools for enhancing creative thought, I think we need to explore more deeply the "conversation"—the information flow—that occurs between a user and their tools. This is because [[Thinking with a tool involves a close coupling between user and tool]]. This implies thinking less about screens and manipulation of objects, and more about the information and state changes in tool and mind that occur when using a tool.

What lens could we adopt to better see these relationships? Cybernetics might be one! As Gordon Brander writes in [Notes are conversations across time](https://subconscious.substack.com/p/notes-are-conversations-across-time), drawing on the ideas behind Conversation Theory:

>Cybernetics shifts our focus away from objects, and toward the flow of information between objects. Design through the lens of Conversation Theory is not about features and screens. Design is the making and breaking of cybernetic feedback loops.
