It is extraordinarily difficult to design interfaces that take advantage of muscle memory because doing so requires thinking deeply about the long-term use of an application and how users will "grow into it." It means thinking about and understanding a user's *path to mastery* within an application.

Users do not typically develop muscle memory for an application unless they use it regularly and intentionally learn the shortcuts and gestures needed to use an application efficiently. This requires a few things:

* Motivated users who want to learn and master the shortcuts and gestures
* Entry points and methodologies for learning these shortcuts and gestures
* Opportunities to reify the learning

Dreyfus has called this kind of muscle memory "muscular gestalts," drawing on Merleau-Ponty. The idea is that no user has stored these behaviors in their mind, per se, but instead they simply have a bodily response to a specific situation or solicitation of the world (in this case the state of a software application).
